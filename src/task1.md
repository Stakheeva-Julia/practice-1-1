# Задание 1. Разбор tsconfig.json

Откройте `tsconfig.json` в корне проекта и для каждой строки напишите
**своими словами**, что она делает. Не копируйте документацию —
объясните так, как будто рассказываете одногруппнику.

## compilerOptions

### target
> Проверка версии JavaScript для перевода в TypeScript (новая или старая)

### module
> Какая система модулей будет в итоговом JavaScript (новая или старая)

### moduleResolution
> Как именно TypeScript ищет данные для перевода

### strict
> Жескость проверки: true-жесткая, false-мягкая

### strictNullChecks
> Если функцияя false, то она позвозяет null и undefined присвоить означение обычных переменных, если true, то они становятся самостоятельными переменами

### esModuleInterop
> Упрощает импорт старых библиотек (включает совместимость)

### skipLibCheck
> Если функция включена, то TypeScript не будет проверять глубоко файлы чужих библиотек. Если выключена, то проверка будет глубокой

### forceConsistentCasingInFileNames
> Когда функция включена то при импорте файлов требуется использовать один реест в его названии

### outDir
> Путь, куда складываются файлы

### rootDir
> Где находится исходная директория

## include
> Какие файлы TypeScript будет брать в работу и их каких папок

## exclude
> Настройка того, что будет взаимодействовать с TypeScript, а что не будет
